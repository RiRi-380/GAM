# GAM v2.3.0

## 日本語

### アセットの一括変更と切り替えセット

- 複数のアセットを選んで、有効・無効・除外の状態をまとめて変更できます。階層グループを変更すると、配下のアセットと、そのグループに今後追加する子要素の初期状態にも反映します。
- 設定で差分プレビューを有効にすると、一括変更やグループ操作、「すべて無効」の確定前に、状態が変わるアセット数と購読中アドオンの ON/OFF 差分を確認できます。初期値はオフです。購読情報を取得できない場合、アドオンの件数は「不明」と表示します。
- ツールバーの「切り替えセット」で、通常アセットと Subscribe の状態に名前を付けて保存し、後から呼び出せます。適用は1回の Undo で取り消せます。セット保存後に追加したアセットはそのまま使えます。GMod 実行中に変更した状態は、ゲーム終了後に反映します。

### 共有、反映、履歴

- 固定アセットと Bundle の `.gam` 取り込みプレビューから、未購読の Workshop ID を1行に1件ずつコピーできます。
- 起動時のパス確認で「あとで」を選ぶと、GMod と Workshop の検出先が両方そろっている場合は今回だけ使います。検出先がそろわない場合は、保存済みの設定で起動を試みます。
- GMod の実行判定に、GAM が実際に使用しているインストール先を使います。パス移行では、確認後に対象が変わった場合に再確認し、既存の無効化設定を保護します。
- 追加スキャンでもキャッシュされた GMA のデータ範囲を検査します。ファイルの移動・消失・復帰を一覧と履歴の詳細に反映し、不明な容量と 0 B を区別します。Workshop の作成日と更新日は個別に確認します。
- アセットへのドラッグ追加を Undo したときに、検索結果や選択に古い状態が残る問題を修正しました。
- 設定画面の各項目へ移動したときにカードの上端が揃うようにし、選択中のアドオンを青い細枠と小さな丸いチェックで表示するようにしました。

- 起動時の Workshop フォルダ検査を並列化し、大量のアドオンがある環境で一覧の読み込みを高速化しました。

### 更新方法

- Setup 版は GAM の更新通知か `GAM-Setup-2.3.0.exe` から更新できます。
- Portable 版は GAM を終了し、新しい ZIP を展開してファイル一式をそろえて起動してください。

配布対象は Windows x64 です。Setup と Portable の実行ファイルは Windows コード署名なしで配布します。

## English

### Bulk asset changes and Switch Sets

- Select multiple assets and set them to Enabled, Disabled, or Excluded in one operation. Changing a group also updates its descendant assets and the default state for new children in that group hierarchy.
- Enable the optional preview in Settings to review how many assets and subscribed add-ons will change before confirming a bulk edit, group action, or Disable All. The preview starts off. Add-on counts are shown as unknown when subscription data is unavailable.
- Use Switch Sets in the toolbar to save and recall named combinations of regular asset and Subscribe states. One Undo reverts an applied set. Assets added after you saved the set keep their state. Changes made while GMod runs take effect after the game closes.

### Sharing, applying changes, and history

- Copy missing Workshop subscription IDs from fixed asset and bundle `.gam` import previews, one ID per line.
- Choose Later at startup to use the detected GMod and Workshop paths for the current session when both are available. If detection is incomplete, GAM tries the saved paths.
- GAM checks the installation it is actually using when detecting whether GMod is running. Path migration asks for confirmation again if its targets change and protects existing disabled add-on settings.
- Incremental scans validate the data bounds of cached GMA archives. The list and history details reflect moved, missing, and restored files, and distinguish unknown sizes from 0 B. Workshop creation and update dates are checked independently.
- Fixed stale search results and selections when undoing a drag-and-drop addition to an asset.
- Settings navigation now aligns the selected card with the top of the view. Selected add-ons use a thin blue outline and a small circular check mark.

- Workshop folders are checked in parallel during startup to load large add-on libraries faster.

### Updating

- For Setup, use GAM's update notification or run `GAM-Setup-2.3.0.exe`.
- For Portable, close GAM, extract the new ZIP, and launch it with all the extracted files in place.

The release targets Windows x64. The Setup and Portable executables are distributed without Windows code signing.
