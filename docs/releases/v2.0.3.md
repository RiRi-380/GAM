# GAM v2.0.3

GAM 2.0.3 is the published updater reliability release following 2.0.1. The
v2.0.2 tag produced no Release or downloadable binaries because its release
gate stopped on two timing-sensitive tests; 2.0.3 includes deterministic test
fixes and the same product correction.

## Changes

- The installed-build updater now waits for the Setup process itself instead
  of the entire process tree. The verified update package and hidden launcher
  therefore delete themselves after Setup finishes while the updated GAM stays
  open.
- Setup exit-code validation, failure logging, HTTPS download, GitHub SHA-256
  asset-digest verification, in-place upgrade, and automatic relaunch remain
  unchanged.
- A process-level regression test proves that a long-running relaunched child
  cannot delay package or launcher cleanup.
- Responsive overlay tests now observe the real pane-close event instead of
  depending on runner scheduling within a 120 ms animation window.
- The public updater E2E verifies update, stable relaunch, settings/GMod/
  Workshop preservation, and the historical v2.0.0 launcher's eventual
  cleanup behavior.

## Updating

Installed GAM 2.0.0 and 2.0.1 builds can detect 2.0.3 through GAM's update
check. Their first update is initiated by the older updater, so its temporary
Setup and hidden launcher can remain until that newly opened GAM is closed
once. GAM 2.0.3 contains the fix; updates initiated by 2.0.3 and later clean
those temporary files immediately after Setup exits.

The installation directory and current-user or all-users mode are preserved.
The update does not remove or move `%APPDATA%\GmodAddonManager`, GMod settings,
Workshop payloads, Steam subscriptions, Asset Groups, or `.gam` data.

Portable builds receive the Portable ZIP and still require manual extraction;
they do not install a second registered copy.

## Files

- `GAM-Setup-2.0.3.exe` - versioned installer
- `GAM-Setup.exe` - stable installer filename used by installed-build updates
- `GAM-Portable-2.0.3.zip` - self-contained portable build
- `GAM-UpdateManifest-2.0.3.json` and `.sig` - signed compatibility metadata
  for legacy GAM v1.0.3-v1.0.5 update clients
- `SHA256SUMS.txt` - SHA-256 checksums for all release files

Setup and Portable packages are self-contained Windows x64 builds. A separate
.NET runtime or Visual C++ Redistributable is not required. The executables are
not Authenticode-signed, so Windows SmartScreen may show a warning; the release
checksums can be used to verify a download manually.
