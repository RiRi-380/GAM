# GAM v2.0.1

GAM 2.0.1 is a focused interaction and update-validation release on top of the
2.0.0 public baseline. It does not change the configuration or `.gam` schema.

## Changes

- Custom Assets and Asset Groups can now be reordered by pressing a card and
  dragging it directly. The previous 360 ms stationary hold is no longer
  required.
- A small movement threshold still protects normal clicks. Clicking an Asset
  selects it, clicking an Asset Group opens it, and dragging suppresses that
  click action once reordering begins.
- The existing ordering rules remain intact: `Subscribe Asset` and
  `GMod Disabled Addons` stay fixed, while favorite and normal entries remain
  inside their respective sections.
- Direct dragging works for mixed Assets and Asset Groups at the root and in
  nested Asset Groups. The chosen order is saved atomically as before.
- Creating an Asset Group now stays in the current location and asks before
  opening the new Group.
- Creating an Asset from the selected-Addon destination dialog now reports
  duplicate names and creation failures instead of failing silently.
- Asset Group cards now identify their details action as the place to edit
  Group structure, including moving existing Assets into the Group.

## Updating

Installed GAM 2.0.0 builds can detect this release through GAM's update check.
After the user chooses to update, GAM downloads the stable Setup asset over
HTTPS, verifies its GitHub SHA-256 asset digest, upgrades the registered copy in
place, and relaunches GAM. The installation directory and current-user or
all-users mode are preserved.

Portable builds receive the Portable ZIP and still require manual extraction;
they do not install a second registered copy.

The upgrade does not remove or move `%APPDATA%\GmodAddonManager`, GMod settings,
Workshop payloads, or Steam subscriptions. Configuration schema 7 and `.gam`
Bundle v4 remain unchanged, so no profile migration is performed by this
release.

## Files

- `GAM-Setup-2.0.1.exe` - versioned installer
- `GAM-Setup.exe` - stable installer filename used by installed-build updates
- `GAM-Portable-2.0.1.zip` - self-contained portable build
- `GAM-UpdateManifest-2.0.1.json` and `.sig` - signed compatibility metadata
  for legacy GAM v1.0.3-v1.0.5 update clients
- `SHA256SUMS.txt` - SHA-256 checksums for all release files

Setup and Portable packages are self-contained Windows x64 builds. A separate
.NET runtime or Visual C++ Redistributable is not required. The executables are
not Authenticode-signed, so Windows SmartScreen may show a warning; the release
checksums can be used to verify a download manually.
