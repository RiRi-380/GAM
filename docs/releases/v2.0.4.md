# GAM v2.0.4

GAM 2.0.4 fixes the Asset Group member-configuration experience. Opening
"Configure assets" no longer creates a second modal window directly over the
Asset Group details dialog.

## Changes

- Asset Group details and member configuration now use two exclusive pages in
  the same window, removing the overlapping-dialog layout.
- "Back to details" and Escape discard temporary member-selection changes,
  while "Apply structure" keeps them pending until the user saves the Asset
  Group details.
- Closing the window while configuring members returns to the details page,
  preserving the previous two-step cancellation behavior.
- Keyboard focus moves to visible controls when entering or leaving the
  configuration page.
- Regression tests cover page exclusivity, pending-member apply and discard
  behavior, focus visibility, and the absence of a nested owned window.

## Updating

Installed GAM builds can receive 2.0.4 through the normal update prompt. The
installation directory and current-user or all-users mode are preserved. The
update does not remove or move `%APPDATA%\GmodAddonManager`, GMod settings,
Workshop payloads, Steam subscriptions, Asset Groups, or `.gam` data.

Portable builds receive the Portable ZIP and still require manual extraction;
they do not install a second registered copy.

## Files

- `GAM-Setup-2.0.4.exe` - versioned installer
- `GAM-Setup.exe` - stable installer filename used by installed-build updates
- `GAM-Portable-2.0.4.zip` - self-contained portable build
- `GAM-UpdateManifest-2.0.4.json` and `.sig` - signed compatibility metadata
  for legacy GAM v1.0.3-v1.0.5 update clients
- `SHA256SUMS.txt` - SHA-256 checksums for all release files

Setup and Portable packages are self-contained Windows x64 builds. A separate
.NET runtime or Visual C++ Redistributable is not required. The executables are
not Authenticode-signed, so Windows SmartScreen may show a warning; the release
checksums can be used to verify a download manually.
