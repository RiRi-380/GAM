# GAM v2.1.0

## 主な変更

- Subscribe Assetへ「すべて除外 / Exclude All」を追加しました。
  - `ON`: 購読中Addonを有効化元にします。
  - `OFF`: Subscribeの土台だけを無効にします。Enabled Custom Assetは引き続き有効化元になります。
  - `すべて除外`: 現在購読中の全Addonを強制的に無効にし、Custom Assetからの有効化より優先します。
- ツールバーの「すべて無効」は従来どおり、Subscribeと有効なCustom AssetをOFFにする別操作です。
- 希望状態の理由表示、日英tooltip、キーボード・支援技術向けHelpTextを追加しました。
- Windows self-contained runtimeを.NET 10.0.10 security patchへ更新しました。
- Portable/Setupへproduction dependency graphに対応した第三者license/noticeを同梱し、Release工程で自動検証します。

## 設定移行について

- 初回起動時にconfiguration schema 3からschema 4へ自動移行します。
- 購読履歴、GAM/GModの状態baseline、pending journal、Custom Asset、GMod Disabled Addonsは保持されます。
- 移行前の設定は `%APPDATA%\GmodAddonManager\config.json.pre-schema-4.bak` に保存されます。
- schema 4へ移行したprofileはv2.0.1以前では開けません。ダウングレードする場合は、GAMとGModを終了してから現設定を退避し、上記backupを`config.json`へ戻してください。

## 配布物

- `GAM-Setup-2.1.0.exe`: インストーラ
- `GAM-Setup.exe`: 更新導線向け固定名インストーラ
- `GAM-Portable-2.1.0.zip`: 複数ファイル構成のPortable版

インストーラは未署名のため、Windows SmartScreenが警告する場合があります。
