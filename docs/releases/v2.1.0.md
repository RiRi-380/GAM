# GAM v2.1.0

不具合を問い合わせるときに使える「診断情報の書き出し」を追加し、変更の反映状況が正しく表示されない問題を修正しました。

## 診断情報の書き出し

**設定 → ログ → 診断情報を作成…** から内容を確認し、テキストファイルに保存できます。

- GAMのバージョン・OS、アセットやグループの件数、反映中・保留・競合の状態、最近のエラー分類をまとめます。
- アセット名、メモ、アドオンID、個人のパス、認証情報、ログ本文は含めません。自動送信もしません。
- 情報を取得できなかった場合は「不明」と表示します。日本語・英語に対応しています。

購読件数はGAMが前回取得した情報です。診断を作成してもSteamへの再問い合わせやアドオンの状態変更は行いません。ログの集計は直近7日分の対象ファイルの末尾に限り、ゲーム内でのアドオンの読み込み成功を保証するものではありません。

## 修正した不具合

- 変更の反映が失敗したあとも「適用中」の表示と進捗表示が残る問題。
- 反映中に次の変更が保留された場合、完了した処理を「適用中」と表示する問題。
- 競合によって反映が中止された場合に「準備完了」と表示する問題。
- GMod終了と反映結果の通知順序によって表示が変わる問題。実際の反映処理の開始・終了をもとに表示するよう変更しました。

## 更新方法

- **Setup版**：GAMの更新通知、または `GAM-Setup-2.1.0.exe` から上書き更新してください。事前のアンインストールは不要です。
- **Portable版**：GAMを終了して新しいZIPを展開し、ファイル一式をそろえて使用してください。更新通知からはPortable ZIPを取得できます。

v2.0.0から設定形式（スキーマ7）の変更はありません。SetupはGAMのユーザー設定、GMod設定、Workshopデータ、Steamの購読状態を削除しません。v1からの移行では、従来どおりスキーマ7への移行前バックアップが作成されます。移行後に旧v1を起動しないでください。

## 配布ファイル

- `GAM-Setup-2.1.0.exe`：インストーラー
- `GAM-Setup.exe`：アプリ内更新用の同一インストーラー
- `GAM-Portable-2.1.0.zip`：Portable版
- `GAM-UpdateManifest-2.1.0.json` / `.sig`：旧v1の更新クライアント向け署名付き情報
- `SHA256SUMS.txt`：各ファイルのSHA-256

Windows x64向けです。.NET Runtimeの別途インストールは不要です。実行ファイルにはAuthenticode署名がないため、Windows SmartScreenの警告が表示される場合があります。
