# GAM v2.2.1

アドオン一覧から左側のアセットへ直接ドラッグして整理できるようになりました。

## ドラッグでアセットに追加

- 選択したカードを掴むと選択分をまとめて、未選択のカードを掴むとその1件を運べます。通常アセットにドロップすると、元アセットにも残したまま追加します。
- グループの上で約1秒待つと中に入れます。左上の階層名の上で待つと上の階層に戻れます。リストの上下端では、カードの間や余白でも自動スクロールします。
- ドラッグ中に件数と追加先を表示し、終了後は画面下で追加件数と重複件数を確認できます。選択分をドロップした場合は選択を解除します。
- Undoでは、その操作で追加した分だけをまとめて取り消します。表示中のアセットとグループはそのままで、追加先を開いている場合は取り消したカードだけが一覧から消えます。

## 一覧と設定

- アドオンをダブルクリックすると、既定のブラウザーで対象のSteam Workshopページを開きます。
- 追加先を選ぶダイアログから追加した後の「追加先を開くか」の確認を、既定で非表示にしました。設定の「詳細設定」で再表示できます。
- ドロップによる追加の保存やGModへの状態反映中も、処理中表示が更新されます。一覧の位置と表示中のサムネイルを保ちながら結果を反映します。

## 更新方法

- Setup版はGAMの更新通知か、`GAM-Setup-2.2.1.exe` から更新できます。
- Portable版はGAMを終了し、新しいZIPを展開してファイル一式をそろえて起動してください。

GAM構成のスキーマはv2.1.0と同じ7です。配布対象はWindows x64です。
