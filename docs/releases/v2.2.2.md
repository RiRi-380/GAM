# GAM v2.2.2

アドオンの状態を確認しやすくし、一覧の絞り込みや `.gam` の共有を改善しました。

## アドオン一覧と状態表示

- 画面下部の有効・無効の件数がGAMの構成上の値だと分かるようにしました。小さなウィンドウでも保留件数と容量を確認できます。
- カードに現在の状態と選択マークを別々に表示します。種類・タグのフィルターを折りたたみ、適用中の絞り込みをまとめて解除できます。
- 絞り込みや並び替えのたびに全件の状態を読み直す処理を省き、アセットへの所属確認を効率化しました。
- 縦長のサムネイルが必要以上に拡大される問題と、短すぎる `.gma` が利用可能と判定される問題を修正しました。Workshop更新日時が取得できない場合は不明と表示します。

## 共有、反映、履歴

- `.gam` Bundleの取り込み前に、アセットとグループの階層、状態、未購読のWorkshop IDを確認できます。書き出し開始後は進捗を表示します。
- 状態バーの「詳細」から反映の保留・失敗理由を確認し、診断を開けます。再試行できる場合は同じ場所から反映し直せます。
- 別のゲームの `hl2.exe` をGModと誤認しないよう、GModのインストール先を確認します。
- 履歴は追加・削除・変更なしの件数を表示し、差分だけに絞れます。削除した履歴番号は再利用しません。設定から診断や更新へ直接移動できるようにしました。

## 更新方法

- Setup版はGAMの更新通知か `GAM-Setup-2.2.2.exe` から更新できます。
- Portable版はGAMを終了し、新しいZIPを展開してファイル一式をそろえて起動してください。

配布対象はWindows x64です。SetupとPortableの実行ファイルはWindowsコード署名なしで配布します。
