# GAM v2.2.0

## 主な変更

- Asset Groupを追加しました。
  - 複数のAssetや子Groupをまとめ、Group単位で有効・無効・除外を適用できます。
  - Group内へのAsset作成、手動並び替え、お気に入り帯、画像設定、構成編集に対応しました。
  - 子Groupを入れ子にできます。初期上限は1段で、設定から1～10段へ変更できます。
  - Group削除時は、中身を残すか、配下のAsset・Groupもまとめて削除するか選べます。
- Smart Assetを追加しました。
  - Addonの種類またはWorkshopタグを条件にAssetを作成できます。
  - 起動時または更新時に条件を再評価し、新しく購読したAddonも自動で反映します。
  - 条件を失ったAddonは自動で外し、分類情報の一時的な取得失敗では既存メンバーを維持します。
- `.gam`共有を再導入しました。
  - 単一Assetと、複数Asset・入れ子Groupを含むBundleをインポート／エクスポートできます。
  - Asset状態、メモ、Group構造を保存し、任意で画像を圧縮して同梱できます。
  - `.gam`のインポート／エクスポートはSteamの購読状態を変更しません。不足Addonは確認画面に表示します。
- `GMod Disabled Addons`で有効・無効・除外を選べるようにしました。新規作成時の初期状態は無効です。
- Subscribe Assetの状態を新規購読Addonへ一貫して適用し、「すべて除外」も新規購読後に維持されるよう修正しました。
- Addon一覧を改善しました。
  - 購読日時・名前・容量・Workshop更新での並び替えを追加し、選択を保存します。
  - 購読日時をGAMが観測できない過去Addonは「購読日時不明」と表示します。
  - 画像の遅延読み込み、Workshopメタデータ補完、時刻精度、画面分割時のレイアウトを修正しました。
- 試験的設定として、ローカルAddonの読み取り専用表示とAsset構成履歴のUIを追加しました。どちらも初期状態はOFFです。
- 起動、パス復旧、自動更新、インストーラ再起動処理を強化しました。

## 設定移行について

- 初回起動時にconfiguration schema 7へ自動移行します。
- 購読履歴、Asset、`GMod Disabled Addons`、GAM/GModの観測baseline、保留中の書込みjournal、画像参照は保持されます。
- 移行前の設定は `%APPDATA%\GmodAddonManager\config.json.pre-schema-7.bak` に保存されます。
- schema 7のprofileはv2.1.0以前では開けません。ダウングレードする場合は、GAMとGModを終了してから現設定を退避し、上記backupを`config.json`へ戻してください。
