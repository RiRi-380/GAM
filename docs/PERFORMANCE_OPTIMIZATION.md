# GAM パフォーマンス最適化ガイド

## 画像読み込みの高速化

GAMでは画像キャッシュシステムを使用してアドオンのサムネイル画像を高速に表示します。
Windows Defenderやその他のアンチウイルスソフトがキャッシュファイルをスキャンすることで、パフォーマンスが低下する場合があります。

### Windows Defenderの除外設定

以下の手順で、GAMの画像キャッシュディレクトリをWindows Defenderのスキャン対象から除外できます：

1. **Windows セキュリティを開く**
   - スタートメニューから「Windows セキュリティ」を検索して開く
   - または、設定 → 更新とセキュリティ → Windows セキュリティ

2. **ウイルスと脅威の防止を選択**

3. **ウイルスと脅威の防止の設定 → 設定の管理**

4. **除外の追加または削除**

5. **除外の追加 → フォルダー** を選択

6. 以下のフォルダーを追加：
   ```
   %LOCALAPPDATA%\GmodAddonManager\ImageCache
   ```

### 除外設定の効果

- 画像キャッシュの読み書きが高速化されます
- 特に大量のアドオンを管理している場合、顕著な改善が見られます
- セキュリティリスクは最小限です（画像ファイルのみを保存するため）

### その他の最適化設定

1. **SSDの使用を推奨**
   - キャッシュフォルダーがSSD上にあることを確認してください

2. **十分なディスク空き容量**
   - 画像キャッシュには最低1GB以上の空き容量を確保してください

3. **定期的なキャッシュクリーンアップ**
   - GAMは30日以上古いキャッシュファイルを自動的に削除します
   - 手動でキャッシュをクリアする場合は、上記のフォルダー内のファイルを削除してください

## トラブルシューティング

### 画像が表示されない場合

1. インターネット接続を確認
2. Steamが起動していることを確認
3. キャッシュフォルダーへの書き込み権限を確認

### パフォーマンスが改善されない場合

1. タスクマネージャーでディスク使用率を確認
2. 他のアンチウイルスソフトの設定も確認
3. GAMを管理者権限で実行してみる

## 技術仕様

- **3層キャッシュシステム**
  - L1: WeakReference（メモリ効率優先）
  - L2: LRUキャッシュ（50MB制限）
  - L3: ディスクキャッシュ（30日保持）

- **並列処理**
  - 動的スレッド数調整（2-8スレッド）
  - Steam API バッチ処理（100件×5並列）

- **仮想化**
  - ItemsRepeaterによる表示領域のみレンダリング
  - スクロール位置に基づく遅延読み込み
