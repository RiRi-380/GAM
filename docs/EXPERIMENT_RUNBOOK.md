# Experiment Runbook（アーカイブ）

この文書は、GAM v1系のHard／Strict Link方式を評価していた開発実験の履歴です。
GAM v2.0.0の製品手順ではありません。

- v2.0.0はGarry's Modの`addonnomount.txt`を使うSoft方式です。
- `GAM_STRICT_LINK_MODE`、`GAM_EXPERIMENT_FORCE_HARD_DISABLE`など、旧Hard方式を有効にする環境変数は使用しないでください。
- 過去の文書に記載されていた`tools\GmodAddonManager.ExperimentCli`は現在のリポジトリと配布物に存在せず、サポート対象ではありません。
- v2.0.0の操作・検証は[README](../README.md)と[リリースチェックリスト](RELEASE_CHECKLIST.md)に従ってください。

旧方式の測定記録が必要な場合はGit履歴を参照してください。旧手順を現在のGMod／GAM環境で実行しないでください。
